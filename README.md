# terraform-azurerm-subnets

Creates Azure subnets inside an existing virtual network, one per entry in the `subnets` map. Each subnet is named through the Raring Group context module using the map key.

Part of the [Raring Group](https://github.com/raringgroup) Terraform module library.

## Usage

```hcl
module "subnets" {
  source = "git::https://github.com/raringgroup/terraform-azurerm-subnets.git?ref=v0.1.0"

  context = module.context.self

  resource_group_name  = "<resource-group-name>"
  virtual_network_name = "<virtual-network-name>"

  subnets = {
    "<subnet-key>" = {
      address_prefixes = ["<cidr>"]
    }
    "<delegated-subnet-key>" = {
      address_prefixes = ["<cidr>"]
      delegation = {
        name         = "<delegation-name>"
        service_name = "Microsoft.Web/serverFarms"
        actions      = ["Microsoft.Network/virtualNetworks/subnets/action"]
      }
    }
  }
}
```

Naming and tagging come from [`terraform-null-context`](https://github.com/raringgroup/terraform-null-context). Add `_context.tf` to the calling configuration and pass `context = module.context.self`.

See [`examples/`](examples/) for complete, runnable configurations (`complete`, `private-subnets`, `public-subnets`).

### Naming and context

The module uses `azurerm_subnet` directly. Naming and the enabled flag come from the Raring Group context module. `_context.tf` declares the root context (`terraform-null-context`); each subnet gets a child context from the same module, named from the `subnets` map key with the `snet` attribute.

### Inputs

All inputs are required (no defaults). Context inputs (`enabled`, `namespace`, `environment`, `stage`, `name`, `attributes`, `tags`, ...) are declared in `_context.tf`.

| Name | Type | Description |
|------|------|-------------|
| resource_group_name | `string` | Resource group that holds the virtual network |
| virtual_network_name | `string` | Virtual network the subnets are created in |
| subnets | `map(object)` | Subnets keyed by name. Per subnet: `address_prefixes` (required), `default_outbound_access_enabled` (`false` makes a private subnet), `private_endpoint_network_policies`, `private_link_service_network_policies_enabled`, `service_endpoints`, `delegation` (`name`, `service_name`, `actions`) |

### Outputs

| Name | Description |
|------|-------------|
| ids | Map of subnet key to subnet ID |
| names | Map of subnet key to generated subnet name |
| address_prefixes | Map of subnet key to address prefixes |
